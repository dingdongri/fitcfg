# 시나리오 벤치: HF Trainer 기본값 vs fitcfg (예측 기반 시뮬레이션)

- 상수: 문헌 사전값(보정 전) · 시나리오 360개 = 모델 4 × method 3 × GPU 5 × GPU 수 [1, 2] × seq [1024, 2048, 4096]
- 공통: global batch 16, CPU RAM 128GB, 안전계수 0.90
- ⚠️ 모두 cost model **예측**으로 판정한 값이다. 예측 자체의 정확도는 `calibrate.py`(실측 MAPE, OOM 판정)로 따로 보인다.

## 요약
| 지표 | 값 |
|---|---|
| 기본값이 OOM인 시나리오 | **336/360 (93%)** |
| 그중 fitcfg가 들어가는 설정을 찾음 (구제율) | **261/336 (78%)** |
| 수동 탐색이 첫 성공까지 겪는 OOM 실패 | 평균 **5.6회** (≈ GPU 22분 낭비, 1회 4분 가정) → fitcfg 0회 |
| 수동 탐색은 못 찾고 fitcfg만 찾음 | 9개 |
| fitcfg 추천 vs 수동 탐색 첫 성공 설정의 처리량 | 중앙값 **1.00×** (최대 3.03×) |

수동 탐색 순서: micro-batch 8→4→2→1 → checkpointing 켜고 8→1 → (Full) 8bit AdamW → ZeRO-Offload → ZeRO-3 offload.
